# Yori

> *Your Quiet Desk Companion.*

Yori is a handcrafted desktop companion that turns an old iPhone into something alive - expressive eyes on a black screen, listening, thinking, and responding.

## What is Yori?

An old iPhone sits on your desk. Its screen is black, save for two white, rounded eyes. They blink slowly. They drift. They follow you. When you speak, Yori listens - and answers, warmly, in a voice that feels familiar.

Yori is not an app. It is a presence.

## Features

- **Listening** - Yori listens naturally and responds like a thoughtful companion.
- **Companionship** - Yori quietly stays beside you throughout your workday.
- **Personality** - Expressive eyes and subtle emotions make every interaction feel alive.
- **Your API Key** - Use OpenAI, Anthropic, or any model you trust. You are in control.
- **Privacy** - Runs locally whenever possible, keeping your conversations close to home.
- **Desktop Companion** - Always there. Never intrusive. Just quietly sharing your workspace.

## How It Works

```
Old iPhone   WiFi   Local Python Backend   LLM API   Yori Speaks
```

## Website

The landing page is a single-page HTML/CSS/JS site with:
- Animated phone mockup with blinking, cursor-following eyes
- Interactive "Wake Yori" demo
- Scroll-reveal animations
- Warm paper-grain aesthetic

### Run locally

```bash
# Just open index.html in your browser, or use any static server:
npx serve .
# or
python -m http.server 8000
```

## Tech Stack

| Layer | Technology |
|---|---|
| Companion Display | iPhone (any model) |
| Communication | WiFi / WebSocket |
| Backend | Python |
| AI Model | LLM API (OpenAI/Anthropic) |
| Website | HTML + CSS + Vanilla JS |

## Philosophy

Every design choice asks: *does this feel like meeting a small, calm, handcrafted companion - or like using software?*

If it feels like software, slow it down and warm it up.
